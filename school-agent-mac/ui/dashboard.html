MyCourses → Calendar → Subscribe → pick the course in the dropdown → copy the URL. One class per feed link.
Why isn't there a Brightspace login?
Brightspace's account API is locked behind RIT's IT department — students can't self-issue access. The calendar feed link is D2L's own self-service alternative: no password ever touches this app, and you can invalidate the link any time from MyCourses (Subscribe → Reset).
